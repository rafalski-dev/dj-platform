# DJ Platform

A reusable template platform for DJs and bands — landing page, authentication, 
and a customer dashboard in one system.
## Tech Stack
Next.js (App Router), shadcn/ui + Tailwind, React Hook Form + Zod for multi-step forms, PostgreSQL database.

## Design
Modern, luxury, warm and black palette, very cozy — gold accents, elegant typography, 
and Motion (Framer) for smooth, subtle animations.
